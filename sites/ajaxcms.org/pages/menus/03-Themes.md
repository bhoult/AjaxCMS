# Theme Demos

View all available AjaxCMS themes in action. Each theme includes an animated canvas background and coordinated color scheme.

<a href="/sites" class="btn btn-primary btn-lg">Browse All Themes</a>

## Available Themes

The theme demo site showcases all the built-in animated backgrounds:

- **Gears** - Rotating mechanical gears
- **Network** - Animated network nodes and connections
- **Plasma** - Colorful plasma effect
- **GL City** - 3D cityscape with Three.js
- **Night City** - Dark cityscape theme
- **Kaleidoscope** - Symmetrical patterns
- **Bubbles** - Floating bubble animation
- **Ribbons** - Flowing ribbon effects
- **And many more...**

## Creating Custom Themes

Each theme consists of two files in the `themes/` directory:

1. **background.js** - Canvas animation code
2. **theme.css** - Color scheme and styles

See the {{a | 01-Getting_Started.md | Getting Started guide}} for details on theme development.
