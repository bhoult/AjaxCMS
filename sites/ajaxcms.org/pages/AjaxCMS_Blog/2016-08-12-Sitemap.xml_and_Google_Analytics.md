## SEO and Sitemaps
**Updated 2025:** AjaxCMS now uses a Node.js server that provides JSON API endpoints for directory listings. This server can be extended to generate XML sitemaps programmatically.

### Sitemap Generation Options

**Option 1: Static Sitemap (Simplest)**
Create a `sitemap.xml` file manually in your site's root directory. For small sites that don't change frequently, this is the easiest approach:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>http://yoursite.com/</loc>
    <lastmod>2025-10-31</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  <!-- Add more URLs here -->
</urlset>
```

**Option 2: Dynamic Sitemap via Node.js**
The Node.js server (`server.js`) can be extended to add a `/sitemap.xml` endpoint that generates sitemaps dynamically from your pages directory. This would use the same recursive directory listing logic already in place.

**Option 3: Build Script**
Create a simple build script that runs when you deploy:

```javascript
// generate-sitemap.js
const fs = require('fs');
const path = require('path');

// Recursively find all .html and .md files
// Generate sitemap.xml
// Save to site root
```

Run it before deployment: `node generate-sitemap.js && npm start`

### Search Engine Considerations
Single-page applications (SPAs) like AjaxCMS require special consideration for SEO:

- **URL Structure**: AjaxCMS uses `?page=` query parameters, which search engines can index
- **Meta Tags**: Update `<title>` and meta tags dynamically for each page
- **History API**: Browser history is properly managed for back/forward navigation
- **Content Accessibility**: All content is accessible via direct URLs

Modern search engines (Google, Bing) execute JavaScript and can index AJAX-loaded content, but providing a sitemap helps ensure complete indexing.

## Google Analytics Integration
AjaxCMS includes built-in support for Google Analytics with proper single-page application (SPA) tracking. Since pages load via AJAX without full refreshes, we need to manually track page views.

### How It Works
The Google Analytics tracking code is in `index.html`, and the pageview tracking has been moved to trigger after each page load in `js/ajaxcms.js`:

```javascript
// Step 8: Track page view in Google Analytics (if initialized)
if (typeof ga === 'function') {
    ga('send', 'pageview', location.href);
}
```

This ensures every AJAX page navigation is tracked as a separate pageview, giving you accurate analytics data.

### Setup
1. **Get your tracking ID**: Sign up for [Google Analytics](https://analytics.google.com) and create a property
2. **Configure in index.html**: At the top of your `index.html` file, find the `ajaxcms_google_analytics` variable:
   ```html
   <script>
   var ajaxcms_google_analytics = 'UA-XXXXXXXX-X'; // Replace with your ID
   var ajaxcms_splash_time = 5000;
   var default_background = 'network';
   </script>
   ```
3. **Set to empty to disable**: `var ajaxcms_google_analytics = '';`
