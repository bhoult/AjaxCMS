## Schematic Theme

Welcome to the Schematic theme for AjaxCMS. This theme features a dynamically generated electrical schematic that continuously evolves in the background, creating a unique technical aesthetic perfect for engineering portfolios, hardware projects, and technical documentation.

### About This Theme

The Schematic theme delivers a professional engineering aesthetic with its continuously generated electrical schematics in the background. Watch as resistors, capacitors, ICs, transistors, and other electronic components materialize and connect together in real-time, creating an authentic circuit diagram that's always changing.

This theme is perfect for electrical engineers, hardware developers, makers, electronics hobbyists, PCB designers, or any technical project that needs a professional engineering presence. The clean, technical drawing style maintains excellent readability while providing constant visual interest.

### Key Features

The Schematic theme brings technical precision to every element:

- **Dynamic Schematic Generation**: Real-time animated electrical schematics with authentic component symbols
- **Component Library**: Resistors, capacitors, ICs, transistors, diodes, power symbols, and ground connections
- **Manhattan Routing**: Wire traces connect components using proper orthogonal (right-angle) routing
- **Fade Animations**: Components smoothly fade in and out, creating constant evolution
- **Technical Typography**: Roboto Mono for body text and Titillium Web for headings provide crisp readability
- **Clean Professional Design**: Paper-white containers with technical borders and subtle shadows
- **Grid Background**: Subtle technical grid creates authentic drafting paper aesthetic
- **Component Labels**: Authentic electronic component values (1kΩ, 10µF, 2N2222, etc.)

### Design Elements

Every component is rendered with precision. The animation generates proper electronic symbols including zigzag resistors, parallel-plate capacitors, IC packages with pins, transistor symbols with base/collector/emitter, diode arrows, and power/ground symbols. Wire traces use green color (#22aa55) reminiscent of actual PCB traces, connecting components with intelligent Manhattan routing that respects the grid.

The theme uses a clean paper-white background (#f5f5f0) with technical gray borders and components drawn in engineering black. Content containers float above the schematic with subtle shadows, maintaining perfect readability while the circuit evolves beneath.

### Technical Excellence

Built with modern Bootstrap 5 compatibility, the Schematic theme uses HTML5 Canvas for smooth 60fps animation. Components are object-oriented JavaScript classes with proper fade-in/fade-out lifecycles. The animation system automatically manages component density, ensures proper spacing, and prevents overlap.

Typography leverages Google Fonts with Roboto Mono providing technical monospace character for body text and Titillium Web delivering clean sans-serif headers. All components follow responsive design principles, scaling beautifully from mobile to desktop.

### Perfect For

This theme excels for: electrical engineering portfolios, hardware startup sites, maker project documentation, PCB design showcases, electronics tutorials, embedded systems blogs, IoT project sites, robotics teams, STEM education platforms, technical documentation, or any project requiring an authentic engineering aesthetic.

The schematic aesthetic captures technical expertise immediately while remaining professional and clean. It's particularly effective for demonstrating attention to detail and technical precision, making it ideal for showcasing engineering work and technical capabilities.

### Live Animation

The background continuously generates new components at random positions on a technical grid. Each component has a lifetime of approximately 5 seconds, fading in smoothly, remaining visible, then fading out to make room for new circuits. Wire traces connect nearby components automatically, creating authentic circuit topology that evolves organically over time.
