## Conway's Game of Life Theme

Welcome to a mesmerizing demonstration of **cellular automaton** patterns evolving in real-time. Watch as simple rules create complex, ever-changing life forms across your screen.

### About This Theme

Conway's Game of Life is one of the most famous examples of emergence in mathematics. Created by mathematician John Conway in 1970, this zero-player game demonstrates how complex patterns can arise from remarkably simple rules.

**The Four Rules:**
1. **Birth**: Any dead cell with exactly 3 live neighbors becomes alive
2. **Survival**: Any live cell with 2 or 3 neighbors stays alive
3. **Loneliness**: Cells with fewer than 2 neighbors die
4. **Overcrowding**: Cells with more than 3 neighbors die

### Visual Experience

This theme brings the Game of Life to your browser with a matrix-inspired green aesthetic. Watch patterns emerge, evolve, and interact:

- **Gliders** - Small patterns that move across the grid
- **Oscillators** - Structures that repeat in cycles
- **Still Lifes** - Stable patterns that never change
- **Complex Emergent Behavior** - Unpredictable evolution from randomness

### Technical Implementation

The animation runs on a toroidal grid where edges wrap around, creating an infinite playing field. Each generation is computed in real-time using optimized JavaScript, demonstrating how computational simplicity can yield visual complexity.
