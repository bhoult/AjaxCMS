## Mirrored Theme

Welcome to the Mirrored theme for AjaxCMS. This theme showcases perfect quadrant symmetry with animated nodes that create mesmerizing reflective patterns across your screen. Watch as connected nodes dance and mirror themselves in all four corners, producing an elegant geometric ballet.

### About This Theme

The Mirrored theme brings sophisticated geometric aesthetics to your AjaxCMS site. Featuring animated nodes connected by colorful lines that reflect perfectly across four quadrants, this theme creates a hypnotic, symmetrical display that's both modern and elegant. The nodes repel from screen edges using physics-based motion, creating organic yet perfectly balanced movement patterns.

Built with a dark, professional color scheme featuring deep blues, cyan accents, and gradient effects, the Mirrored theme delivers a premium, tech-forward aesthetic. The geometric Poppins font for headings combined with clean Inter for body text reinforces the theme's symmetrical, precise character.

### Key Features

The Mirrored theme provides a unique visual experience:

- **Quadrant Symmetry**: Five nodes animate in one quadrant and mirror perfectly across all four corners, creating kaleidoscopic patterns
- **Color-Cycling Animation**: Lines and nodes continuously cycle through the HSL color spectrum, producing smooth rainbow gradients
- **Physics-Based Motion**: Nodes use velocity vectors and edge repulsion for natural, organic movement that never looks robotic
- **Smooth Fade Trails**: Background slowly fades creating subtle motion blur and trailing effects as patterns evolve
- **Geometric Typography**: Poppins headings with animated glow effects and Inter body text for modern readability
- **Glassmorphism Design**: Semi-transparent containers with backdrop blur create floating panel effects over the animation
- **Gradient Accents**: Cyan-to-pink gradients on headings, buttons, and interactive elements
- **Responsive Layout**: Scales beautifully from mobile to desktop with adaptive spacing

### Design Elements

Every element embraces the symmetrical aesthetic. Content containers feature glassmorphism with semi-transparent dark blue backgrounds, subtle borders with cyan glow, and backdrop blur effects. Buttons use geometric styling with expanding circle hover effects. Links animate with sliding underlines. The navbar maintains perfect alignment with glowing accent underlines on hover.

The color palette centers on deep navy (#1a1a2e) and midnight blue (#16213e) backgrounds with bright cyan (#00d4ff) for accents and coral pink (#e94560) for highlights. All text glows softly, and h1 elements pulse with a breathing animation. The overall effect is futuristic yet elegant, technical yet accessible.

### Technical Excellence

Built for Bootstrap 5 compatibility, the Mirrored theme uses modern CSS custom properties (variables) for easy color customization. The animation runs at 60fps using requestAnimationFrame with efficient canvas rendering. Node physics calculations use the Victor.js 2D vector library for smooth, accurate motion simulation.

Typography leverages Google Fonts with Poppins providing geometric sans-serif headings and Inter delivering clean body text. The theme includes glassmorphism effects using backdrop-filter, smooth CSS transitions on all interactive elements, and custom styled scrollbars for consistency.

### Live Animation

The background continuously animates five nodes that move with physics-based velocity and edge repulsion. Each frame, the nodes update their positions, draw connecting lines between them, and render perfect mirror copies in all four quadrants. Colors cycle through the full HSL spectrum creating rainbow gradients. The result is a mesmerizing, endlessly unique pattern that never repeats exactly the same way twice.
